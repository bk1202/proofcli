# The 30-second demo

[Download/watch the MP4](https://github.com/bk1202/proofcli/releases/download/v0.4.0/proofcli-demo.mp4).

The silent, captioned walkthrough runs for exactly 900 frames at 30 fps. It shows a real exporter changing Grace's amount from `8.25` to `999.00`, an exit-code-only CI step accepting its exit `0`, and ProofCLI rejecting the incorrect JSON and CSV records.

The terminal panels are edited presentations of actual command results, not a continuous screen recording. `demo/src/evidence.json` is generated by executing the exporter and CLI; the composition reads its amounts, messages, and mismatch directly. The shortened ordinary command and selected report fields are labelled in the video. This is a demonstration of missing assertions in CI, not a claim that CI or other testing tools cannot verify data.

To reproduce from the repository root, with Python 3.10+ and Node.js 22+:

```console
python tools/capture_demo.py
cd demo
npm ci
npm run lint
npm run dev
```

Open the printed Studio URL. To export the video:

```console
npm run render
npm run poster
```

The output is `demo/out/proofcli-demo.mp4`; the poster is `demo/out/demo-poster.png`. Dependencies are locked in `demo/package-lock.json` and are used only to build the video. The Python package and GitHub Action do not install them.

[The hosted demo workflow](../.github/workflows/demo.yml) intentionally has a successful ordinary job and a failed ProofCLI job. Its failed overall result is the expected demonstration. The separate validation workflow asserts that same failure and remains green only when ProofCLI rejects the broken export.
